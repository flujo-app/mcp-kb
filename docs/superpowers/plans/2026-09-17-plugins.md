# Plugins Plan — sources, plugins, libraries, marketplaces, prompt dialects

> **For agentic workers:** executed with superpowers:subagent-driven-development
> on the branch `plugins`, with wave tasks in their own git worktrees. One PR at
> the end. Every task reads its own brief; nobody reads this whole file except
> the controller.

**Goal:** the config becomes *sources* (named backends), *plugins* (a path under
a source, with Claude's marketplace-entry metadata) and *libraries* (a
marketplace, a list of plugins, or a query over them); prompts are read in the
Claude and Copilot dialects as well as this server's own; a library's `source`
may be a marketplace published in a git repo, a Nextcloud folder or a local
directory, and its `marketplace.json` is what lists the plugins.

**Spec (binding):** `saga/Chapter_1_The_Card_Catalogue.md` §C1.27–§C1.37. The
decisions there win over anything here; this file fixes exact names, shapes and
test cases so the tasks can be dispatched without reading the saga. §C1.33 lists
the ten work items; §C1.34–§C1.37 revise them (no folder selectors; Claude and
Copilot dialects; substitutions; the input-required path).

**Architecture:** `config.py` holds three lists. `plugins/` turns them into
resolved `Plugin`s over shared `Fetch`es (one materialised tree per URL+ref),
reads `marketplace.json` and `plugin.json`, and evaluates selectors.
`sources/` materialises a `Fetch` (the same three backends). `catalogue/`
harvests a plugin into rows, assembles libraries, and serves them at the same
`skill://<library>/…` addresses as today. `mcp/` scopes by library, categories
and tag groups.

**Tech stack:** unchanged — Python ≥3.11, FastMCP 4.0.3, pydantic, pygit2,
webdav4, python-frontmatter.

**Toolchain in the pod:** `PYTHONPATH=/home/coder/.cache/mcp-school-pylib`
(no venv, nothing to install). From a checkout's root:
`python3 -m pytest -q`, `python3 -m ruff check .`,
`python3 scripts/generate_wiki.py --check`. Tests import `kubed` from the
current directory, so each worktree tests its own code.

The ladder, strongest signal first, exactly §C1.34:

1. `declared` other than `auto` wins.
2. Path: a name ending `.prompt.md` → `copilot`. (A `commands/` directory or a
   manifest `commands` entry → `claude` — D1 passes `dialect="claude"` for
   those, so this module does not look at directories.)
3. Frontmatter keys: `agent` or `tools` → `copilot`; `argument-hint`, or
   `arguments` that is a string or a list of strings → `claude`; `arguments`
   that is a list of dicts → `mcp-kb`; `applyTo` or `globs` → `None` (not a
   prompt; the loader skips it with the reason "not a prompt: has `applyTo`").
4. Body: `{{name}}` → `mcp-kb`; `${input:` → `copilot`; `$ARGUMENTS` or
   `$<digit>` → `claude`.
5. Nothing matched: `mcp-kb` (a description and a body are the same in every
   dialect).

**Dialect rules.**

*mcp-kb* (today's loader, unchanged): `description`; `arguments` as objects
with `name`, `description`, `required`, `default`; `{{ name }}` placeholders;
an undeclared placeholder is an error; a required argument cannot have a
default. `title` is `meta.get("title")` or None.

*claude*: `description` → description. `arguments` (a list of names, or one
string of whitespace-separated names) → optional arguments in that order, each
with description `None`. `argument-hint` → description of the free-text
argument (below). If the body contains `$ARGUMENTS`, `$ARGUMENTS[N]` or `$N`,
or no names are declared at all, one optional argument named `arguments` is
appended (description: the `argument-hint`, else "Everything typed after the
command."). Substitution: `$name` for each declared name; `$ARGUMENTS` → the
`arguments` value; `$ARGUMENTS[N]` and `$N` (N = 1–9) → the N-th declared
name's value when names are declared, else the N-th whitespace-split word of
`arguments`; a missing value substitutes `""`. When the body has no
`$ARGUMENTS`/`$N` and no declared names and `arguments` is given non-empty,
append `"\n\nARGUMENTS: " + value` (what Claude Code does). `${CLAUDE_*}`,
`@path` and `!` lines are untouched here. Dropped keys: `name`,
`allowed-tools`, `disallowed-tools`, `model`, `disable-model-invocation`,
`user-invocable`, `when_to_use`, `context`, `agent`, `hooks`, `paths`,
`shell`, `effort`, `license`, `compatibility`, `metadata`. `title`: None.

*copilot*: `description` → description. Every `${input:name}` and
`${input:name:placeholder}` in the body → one optional argument per distinct
name, in first-appearance order, description = the first placeholder text seen
for that name (None when none). Substitution replaces both spellings of a
declared input with its value (`""` when missing). `${selection}`, `${file}`,
`${workspaceFolder}`, `#file:`, `#tool:` untouched. `argument-hint` with no
`${input:}` in the body → the same free-text `arguments` argument as Claude,
appended as `"\n\n" + value` when given. Dropped keys: `name`, `agent`,
`model`, `tools`. `title`: None.

Every dialect: a missing *required* argument raises `MissingArguments` (only
mcp-kb ever marks one required); the dropped keys are logged once per file at
DEBUG as `"prompt %s: ignoring %s (no meaning over MCP)"`.

**Interfaces — `plugins/address.py`.**

```python
@dataclass(frozen=True)
class Address:
    scheme: str
    path: str          # "grafana/skills", "mcp-kb/ai", "/srv/prompts/grafana" (file)
    subdir: str = ""   # after "//", posix, no leading slash
    ref: str | None = None
    def __str__(self) -> str   # canonical: scheme://path[//subdir][?ref=ref]
    @property key -> str       # scheme://path[?ref=ref]   -- the fetch identity

def parse_address(text: str) -> Address
```

Grammar: `scheme` is `[a-z0-9][a-z0-9+.-]*` before `://`; the remainder up to
`?` is split at the **first** `//` into path and subdir; the query may hold
only `ref=<value>` (any other key is a ValueError naming it); `..` anywhere in
path or subdir is a ValueError; an empty path is a ValueError; a `file` path
must start with `/`; a non-file path must not. `str(parse_address(s)) == s`
for a canonical `s`, and `parse_address(str(a)) == a`.
